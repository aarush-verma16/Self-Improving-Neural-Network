# valmorph

Validation-gated self-modifying networks, studied at a scale that fits a MacBook Pro M4 and a 20% slice of an RTX 5080.

The network may change its structure or a learning-rule setting during training. Each proposal is tried on a shadow copy, scored on a held-out probe split, and accepted or rejected. Accepted and rejected proposals are both stored in a Parquet ledger. The research question is whether those edits improve held-out continual learning (Level 1) and whether the editor itself improves (Level 2). Transfer without retuning is a stretch (Level 3). A clean negative result is a valid outcome.

This repository is the whole project. It does not depend on any other codebase.

## Status

Phase 0: foundation. No trained models yet. Hypotheses are pre-registered in `docs/01_RESEARCH_QUESTIONS.md` and have not been tested.

## Setup

Install [uv](https://docs.astral.sh/uv/), then:

```bash
uv python pin 3.12
uv sync --group dev
uv run pre-commit install
uv run python scripts/env_check.py
uv run pytest
uv run python notebooks/00_setup.py
uv run jupytext --sync notebooks/00_setup.py
```

Windows and Linux install torch 2.14.1 from the CUDA 13.2 wheel index. macOS installs the PyPI wheel and uses MPS. `env_check` must print `matmul_ok: true` and the device you expect (`cuda` on the 5080, `mps` on the M4). If it does not, stop. The script will not switch devices or wheels for you.

The process memory fraction defaults to 0.20. That is about 3.3 GB on the 16 GB 5080 and about 4.8 GB on the 24 GB M4.

Notebook workflow: edit `notebooks/00_setup.py`, sync with jupytext, and let pre-commit run nbstripout so ipynb outputs do not land in git.

```bash
uv run python scripts/local_check.py
```
